## 🛠️ Want to Help?

If you are passionate about Bloxd.io, world-building, or scripting and want to help make Astrax even better, we would love your support. Here is how you can get involved:

* 🧪 **Help Test It:** Put Astrax through its paces. Build things in your worlds, try Deep Research, test memory continuity, and report bugs or unusual behavior.
* 🧠 **Help Train It:** Submit working WorldCode, code blocks, and documentation through the **Admin Training Dashboard** so the system can learn more.
* 💡 **Suggestions for Future Updates:** Have an idea for a feature, UI refinement, or research workflow improvement? Share it so it can be considered for the roadmap.
* 📢 **Help Advertise It:** Share the workspace with friends, world members, and fellow creators in the Bloxd community to help grow the user base.

# Release Notes (v1.5): Orbit, Rebuilt Bloxd Knowledge, and Smarter AI

## Overview
**Date:** July 29, 2026

Version 1.5 is a major release — the biggest yet. It introduces Orbit, a dedicated coding mode for Bloxd World Code, alongside a complete rebuild of Astrax's Bloxd knowledge and a smarter multi-model AI system. This is a foundational leap in what Astrax can build and how accurately it answers.

---

### Orbit — Dedicated Coding Mode
* **New coding workspace for Bloxd World Code:** Astrax now includes a dedicated Orbit mode that transforms the interface into a split editor and chat layout.
* **Generate and Revise modes:** Create new code or refine existing code directly inside the workspace.
* **Built-in Bloxd linter:** Inline, hoverable error detection helps surface issues quickly, with a "Fix with Orbit" option for fast follow-up.
* **API-grounded behavior:** Orbit uses real Bloxd functions and callbacks that actually exist, making suggestions more accurate and practical.

### Bloxd Knowledge Rebuild
* **Complete rewrite of Bloxd knowledge:** Astrax's Bloxd knowledge base has been rebuilt with roughly 1,500 lines of verified information.
* **Broader coverage:** The update includes verified details on weapons, blocks, mobs, biomes, crafting, the full coding API, and more.
* **Improved accuracy:** Stats and details are cross-checked so Astrax answers more reliably instead of guessing.

### Smarter Multi-Model AI
* **Smarter model selection:** Astrax now automatically picks the right model for the task, using faster models for general questions and stronger models for coding.
* **Stronger coding performance:** Orbit uses the best available coding model for more capable assistance.
* **Newer model strategy:** Astrax has moved beyond GPT-4o-mini as the default and now uses a broader, more capable range of models.

### Dev Testing Program
* **New tester program:** Trusted testers can now receive an upgraded experience with tools to report issues and flag inaccurate responses.
* **Direct feedback loop:** Reports and feedback go straight to the developer, helping catch bugs and improve accuracy faster.
* **Join the program:** Interested testers can reach out on Reddit to join the team.

### Future Direction
PixelGen is still planned for removal, with Astrax's own built-in image generator targeted for a later release in v2.0.

---

### What's Next
After the major v1.3 and v1.5 releases, the next four updates — v1.6, v1.7, v1.8, and v1.9 — are planned as rapid-fire polish releases. Expect quick fixes, quality-of-life improvements, and steady refinements as Orbit and the rebuilt knowledge base get battle-tested in the wild, all leading up to v2.0.

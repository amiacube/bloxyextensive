# Release Notes (v1.3): Astrax Transition

## Major Platform Upgrade
**Date:** July 26, 2026

Version 1.3 marks the biggest leap yet: TechPixel is now Astrax. What started in Base44 as TechPixel (v1.0 through v1.2) has moved to a new home built in Google AI Studio, bringing a sleeker, more modern experience paired with a faster and more efficient AI.

---

### Platform & Performance Upgrades
* **Astrax Rebrand & New Home:** TechPixel has transitioned into Astrax, now powered by a new experience built in Google AI Studio.
* **Faster and More Efficient AI:** The platform now feels noticeably quicker, smoother, and more responsive.
* **Real API Provider Integration:** Astrax now runs on real API providers such as GitHub Models and Mistral.
* **Memory System Rebuild:** The memory system has been redesigned to be more reliable, useful, and transparent.
* **Occasional API Instability:** Because Astrax relies on live API providers, occasional instability may still occur while improvements continue.

### Deep Research & Productivity
* **Deep Research Improvements:** Compared with the earlier Research experience in v1.1 and v1.2, Astrax now uses a more advanced investigation engine powered by a multi-agent Mistral architecture with live web search and official Bloxd Fandom Wiki API integration.
* **Structured Investigation Workflow:** When enabled, research now breaks complex questions into a multi-step plan and deploys dedicated sub-agents for data gathering, verification, and synthesis, helping eliminate hallucinated items and fake weapon claims.
* **Research UI Enhancements:** The experience now includes a compact purple microscope icon in the composer, real-time research progress cards, animated execution badges, and a polished final report reader with slide-in presentation.
* **Voice Dictation:** Compose prompts and messages hands-free using integrated voice input.
* **Automatic Text Attachments:** Large blocks of pasted text are now automatically converted into organized text attachments, keeping conversations cleaner while preserving formatting and editability.

### Creative Workflow & Continuity
* **Enhanced Creative Workflow:** Visual generation, planning, and project creation are now more tightly integrated into the overall Astrax experience.
* **Refined Interface Experience:** The interface feels more alive and polished, with smoother animations, richer visual effects, and more fluid transitions.
* **Cleaner, More Streamlined Layout:** Navigation and interaction feel less cluttered, helping you move through the experience with less friction.
* **Project Continuity:** Astrax can remember active projects and offer to resume work where you left off, including previously completed systems and recommended next steps.
* **PixelGen Integration:** PixelGen, the image generator, is now fully accessible inside Astrax.

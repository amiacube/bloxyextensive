# Release Notes (v1.9): Neural Expressive UI, Turbo Memory, and Bloxd-Only Accuracy

## Overview
**Date:** August 15, 2026

Version 1.9 is the final release in the rapid-fire v1.6–v1.9 cycle, closing out the road to v2.0. This update brings a redesigned expressive interface alongside major upgrades to memory, accuracy, and speed — making Astrax not only smarter and faster, but better looking and more alive than ever.

---

### Neural Expressive UI
* **Completely redesigned interface:** Astrax now centers the experience around a living neural orb that reacts and animates as it thinks and responds.
* **Cleaner, more premium look:** The layout is sleeker and more modern, with Bloxd-inspired theming that feels more polished and cohesive.
* **More fluid interaction:** Subtle animations make every conversation feel more alive, responsive, and engaging.

### Turbo Memory System
* **Full memory rebuild:** Astrax now uses a smarter extract, store, and retrieve pipeline for durable memory.
* **Personalized recall:** It remembers durable facts about you — such as playstyle, goals, favorite gamemodes, and recurring preferences — and brings them up naturally when relevant.
* **Offline retrieval:** Memory recall runs fully offline with zero latency, keeping responses faster and more seamless.
* **Automatic updates:** Older facts are refreshed when they change, making memory more accurate over time.
* **Transparent controls:** The new "What do you remember about me?" panel lets users view, delete, and clear memories on demand.

### Recipe Cards
* **Structured crafting output:** Crafting answers now show clean recipe cards with item name, materials, quantities, crafting station, and tips.
* **Much easier to scan:** Instead of plain text blocks, crafting info is now presented in a simpler, more readable format.

### Feedback System
* **Real response feedback logging:** Thumbs up and thumbs down now capture the question, answer, model used, and timestamp.
* **Better learning loop:** This helps Astrax detect weak responses and improve over time based on real-world feedback.

### Faster & Smarter Responses
* **Instant offline keyword generation:** API-based keyword search has been replaced with faster offline generation.
* **Reduced wasted API calls:** Response generation is now faster and more efficient.
* **More thorough retrieval:** Astrax gathers more of the relevant context before answering, improving depth and accuracy.
* **Better answer quality:** Knowledge is fed to the AI in a richer, more complete form for stronger final responses.

### Bloxd-Only Accuracy
* **Bloxd-only knowledge lock:** Astrax is now restricted to Bloxd.io knowledge, reducing Minecraft mix-ups and false assumptions.
* **Improved honesty when unsure:** If Astrax does not know something, it now says so instead of guessing.
* **Corrected item data:** Crafting recipes and item stats across the knowledge base have been corrected and cleaned up.

### Natural Conversations
* **More conversational tone:** Astrax now answers in a more natural, human-feeling style instead of choppy stat-sheet responses.
* **Better user experience:** Conversations feel less robotic and more like speaking with a real Bloxd expert.

### Stability & Bug Fixes
* **Fixed message-ordering problems:** Astrax no longer sometimes replies to the previous message instead of the current one.
* **Fixed truncated responses:** Cut-off and incomplete replies are less frequent.
* **Improved filtering logic:** Overly strict response filtering no longer rejects valid short answers.
* **Removed capability-menu dodging:** Astrax no longer leaks internal info or avoids direct questions with generic capability menus.
* **Provider reliability improvements:** The AI provider system has been overhauled for better stability and a cleaner fallback chain.
* **Cleaner app logging:** Logging is now more organized, concise, and easier to debug.

---

### What's Next
The big one is v2.0. This release will bring Astrax's own built-in image generator, replacing PixelGen, alongside more major features and deeper platform upgrades.

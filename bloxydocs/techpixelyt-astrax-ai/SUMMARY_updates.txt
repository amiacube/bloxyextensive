

Release Notes (v1.9)
Date: August 15, 2026
Version 1.9 is the final release in the rapid-fire v1.6–v1.9 cycle, closing out the road to v2.0. This update brings a redesigned expressive interface alongside major upgrades to memory, accuracy, and speed — making Astrax not only smarter and faster, but better looking and more alive than ever.

Neural Expressive UI
- A completely redesigned, more expressive interface centered on a living neural orb that reacts and animates as Astrax thinks and responds.
- A sleeker, more modern look with a cleaner layout and Bloxd-inspired theming for a smoother, more premium feel.
- Subtle, fluid animations make every conversation feel more alive and responsive.

Turbo Memory System
- Complete rebuild of Astrax's memory into a smart extract, store, and retrieve pipeline. Astrax now remembers durable facts about you — your playstyle, goals, favorite gamemodes, and more — and brings them up naturally when relevant.
- Memory retrieval runs fully offline, adding zero latency, and old facts automatically update when they change.
- New "What do you remember about me?" panel lets you view, delete, and clear everything Astrax remembers, giving you full transparency and control.

Recipe Cards
- Crafting questions now display as clean, structured recipe cards — item, materials, quantities, crafting station, and tips — instead of plain text, making them far easier to read at a glance.

Feedback System
- Thumbs up and thumbs down now log real feedback, capturing the question, answer, model used, and timestamp so bad responses can be caught and Astrax keeps improving over time.

Faster & Smarter Responses
- Replaced the API-based keyword search with instant offline keyword generation — noticeably faster responses with no wasted API calls.
- The knowledge-retrieval system is now more thorough, pulling everything relevant to your question and feeding it to the AI uncondensed for richer, more accurate answers.

Bloxd-Only Accuracy
- Locked Astrax to Bloxd.io knowledge only — no more Minecraft mix-ups. If Astrax doesn't know something, it now says so instead of guessing.
- Corrected crafting recipes and item stats across the knowledge base.

Natural Conversations
- Astrax now responds in a natural, conversational style instead of choppy stat-sheets, so it feels like talking to a real Bloxd expert.

Stability & Bug Fixes
- Fixed a message-ordering issue where Astrax could reply to the previous message instead of the current one.
- Fixed truncated and cut-off responses.
- Fixed overly strict response filtering that rejected valid short answers.
- Astrax no longer leaks internal info or dodges questions with capability menus.
- Overhauled the AI provider system for better reliability and a cleaner fallback chain.
- Rewired the app's logging to be detailed, concise, and organized.

What's Next — v2.0
The big one. v2.0 will introduce Astrax's own built-in image generator, finally replacing PixelGen, alongside more major features. Stay tuned.

⚠️ Warning: Orbit and several systems remain in active development (Beta). Performance, reliability, and feature availability may continue to evolve.

Release Notes (v1.5)
Date: July 28, 2026
Version 1.5 is a major release — the biggest yet. It introduces Orbit, a dedicated coding mode for Bloxd World Code, alongside a complete rebuild of Astrax's Bloxd knowledge and a smarter multi-model AI system. This is a foundational leap in what Astrax can build and how accurately it answers.

Orbit — Dedicated Coding Mode
- A full coding workspace built for Bloxd World Code for Astrax. Switch modes and the interface transforms into a split editor + chat layout.
- Generate and Revise modes for writing new code or refining existing code.
- Built-in Bloxd linter with inline, hoverable error detection and a "Fix with Orbit" option.
- Grounded in the real Bloxd API, so Orbit uses functions and callbacks that actually exist.

Bloxd Knowledge Rebuild
- Complete rewrite of Astrax's Bloxd knowledge base — roughly 1,500 lines of verified info covering weapons, blocks, mobs, biomes, crafting, the full coding API, and more.
- Every stat cross-checked so Astrax answers accurately instead of guessing.

Smarter Multi-Model AI
- Astrax now automatically picks the right model for the task — fast for general questions, stronger for coding, and the best coding model in Orbit.
- Moved on from GPT-4o-mini as the default, with a wider, more capable range of models.

Dev Testing Program
- Introduced a Dev Tester program — trusted testers get an upgraded experience with tools to report issues, flag bad responses, and help train Astrax directly.
- Reports and feedback route straight to the dev, making it faster to catch bugs and improve accuracy across the app.
- Want in? Reach out on Reddit (u/Own_Body_9771) to join the tester team.

PixelGen is still planned for removal, with Astrax's own built-in image generator now targeted for a later release (v2.0).

What's Next — Rapid-Fire Updates
After the massive v1.3 and v1.5 release, the next four updates (v1.6, v1.7, v1.8, and v1.9) will be rapid-fire — small, focused polish and refinement releases shipping just 1–2 days apart. Expect quick fixes, quality-of-life improvements, and steady refinements as Orbit and the rebuilt knowledge base get battle-tested in the wild, all leading up to v2.0.

Release Notes (v1.4)
Date: July 28, 2026
Version 1.4 is a refinement release focused on polish. After the major rebuild in v1.3, this update tightens up the experience where it matters most: Deep Research is more dependable, the interface feels cleaner, and Astrax is more stable across the board. It is not a sweeping feature release, but a meaningful step toward making the platform feel faster, calmer, and more reliable.

Deep Research & Knowledge Quality
- More reliable long research runs with fewer mid-session failures or timeouts.
- Better handling of API limits so research is less likely to cut off partway through.
- Cleaner final reports with more consistent formatting and a more polished layout.
- Improved progress feedback so it is easier to see what stage the investigation is in.
- Stronger Bloxd knowledge integration for more relevant research context.

Voice Dictation & Input
- Fixed cases where dictation could fail and return unrelated text instead of a transcription.
- Improved reliability of audio capture and transcription so spoken input is converted to text more consistently.
- Clearer recovery paths when transcription fails, including a more obvious retry option.

Stability & Provider Resilience
- Added automatic retry-with-backoff before failing over, catching many transient errors behind the scenes.
- Smoother provider failover between GitHub Models, Mistral, and Cerebras, with clearer backup-status feedback.
- General bug fixes for the occasional instability introduced by live API providers.

Memory Core 
- Fewer cases of memory failing to save or recall correctly.
- Clearer, more transparent display of what Astrax is actually remembering.

Interface & Experience
- Refined animations and transitions for a smoother overall feel.
- Fixed layout inconsistencies and cleaned up spacing across pages.
- Improved responsiveness on smaller screens.
- Minor accessibility and readability tweaks.

PixelGen is still planned for removal in a future update, with Astrax's own built-in image generator targeted for v1.5.

Release Notes (v1.3)
Date: July 26, 2026
Version 1.3 marks the biggest leap yet: TechPixel is now Astrax. What started in Base44 as TechPixel (v1.0 through v1.2) has moved to a new home built in Google AI Studio, and the difference is immediate — a sleeker, more modern design paired with a noticeably faster, more efficient AI. Under the hood, Astrax now runs on real API providers like GitHub Models and Mistral, and the Memory System has been rebuilt to be far more solid and reliable. Deep Research has taken a major step up too: it now does real web-crawling, shows the steps behind each search, and delivers polished final reports — all integrated directly into the chat. Everything you loved from TechPixel comes with you, including PixelGen, the image generator, now fully accessible inside Astrax. One honest heads-up: because Astrax relies on live API providers, you may notice occasional instability — we’re actively working to smooth that out.

- Advanced Deep Research Upgrade: Compared with the earlier Research experience in v1.1 and v1.2, Astrax now uses a more advanced investigation engine powered by a multi-agent Mistral architecture with live web search and official Bloxd Fandom Wiki API integration.
- Structured Investigation Workflow: Research now breaks complex questions into a multi-step plan and deploys dedicated sub-agents for data gathering, verification, and synthesis, helping eliminate hallucinated items and fake weapon claims.
- Research UI Enhancements: The experience now includes a compact purple microscope icon in the composer, real-time research progress cards, animated execution badges, and a polished final report reader with slide-in presentation.
- Voice Dictation: Compose prompts and messages hands-free using integrated voice input, making interactions faster and more natural.
- Enhanced Memory Core: TechPixel's memory system has been redesigned to focus on usefulness, transparency, and project continuity rather than passive information storage.
- Project Continuity: TechPixel can remember active projects and offer to resume work where you left off, including previously completed systems and recommended next steps.
- Improved Creative Workflow: Visual generation, planning, and project creation are now more tightly integrated into the overall TechPixel experience, reducing friction and streamlining iteration.
- Refined Interface Experience: Smoother animations, richer visual effects, and snappier transitions make the experience feel more alive and polished.
- Cleaner, More Streamlined Layout: The interface feels less cluttered and easier to navigate, helping you get where you need to go with less friction.
- Automatic Text Attachments: Large blocks of pasted text are now automatically converted into organized text attachments, keeping conversations cleaner and easier to navigate while preserving formatting and editability.
BTW, I am planning to remove PixelGen from Astrax for the next version and hopefully create Astrax's built-in image generator in v1.5.

Release Notes (v1.2)
Date: June 12, 2026
Welcome to version 1.2 of TechPixel Agent! This update introduces powerful creative tools, an advanced memory management system, and several quality-of-life interface improvements.

- PixelGen Image Generation: Introducing the newest PixelGen engine directly into the platform.
- Live Activity Feed: Track ongoing processes and system updates in real time.
- Generation History: Access a dedicated history of all your previously generated images.
- Research & Plan Upgrades: Both Research Mode and Plan Mode have been updated to version 0.2.0.
- Dynamic Memory: Teach the Agent personal preferences or context simply by telling it to remember them.
- Memory Control: Full privacy control allows you to completely delete stored memories at any time by asking the Agent to do so.
- Instant Guest Sessions: Access core platform features instantly without signing in. This is perfect for quick testing, evaluations, or low-friction sandboxing.
- Collaboration & Alerts: Added native chat sharing capabilities and system notifications.
- AI-Named Chats: Conversations are now automatically given relevant titles by the AI.
- Data Export: Export your chat logs directly into formatted PDF files.
- Keyword Search: Added a search feature to quickly locate specific keywords within your chat history.
- New Chat Layout: Refreshed the user interface for the New Chat page to improve workspace organization.
- New Top Bar Layout: Cleaned up top-bar navigation for better accessibility.
- Bloxd Updates: Integrated Bloxd updates directly onto the homepage dashboard.
- Interactive Initialization Display: The refreshed home interface now features a simulated terminal diagnostic sequence (techpixel-ai --init) validating connection health across your Web Search link, - Memory Core, and WorldCode API indexing states.
- Live Configuration Manifest: Active developer settings, tracking values like model parameters (gpt-4o), memory status, and core contexts, are now cleanly visualized inside an integrated inline code configuration panel.
- Live Community Sync Footer: A dedicated activity ticker keeps developers locked into fresh platform changes across Reddit, BloxdHub, Fandom, and official game notes in real time.
- Interface Variations: Ambient Layout Model features the glowing graphical platform badge and community network feed. ASCII Terminal Layout Model features the retro stylized title matrix accenting the workspace window focus.
- Staggered Component Ripples: Implemented a staggered loading sequence for the navigation, logo, terminal, configuration, community feed, and call-to-action sections. Each element utilizes a blur-to-sharp transition and a slide-up animation to create a wave-like entry effect across the screen.
- Visual Glow Enhancements: Integrated a live purple glow pulse effect for the primary logo within both the navigation and hero sections.
- Dynamic Multi-Phase Intro Sequence: Includes the Logo Phase where the TechPixel ASCII logo enters with a high-intensity green glow and horizontal scan line sweep; the Burst Phase featuring a synchronized asset explosion of 12 unique items with individual descriptive labels; the Terminal Phase where a boot log terminal displays real-time system initialization status; and the Ripple Exit concluding with four expanding green ripple rings and a screen flash.
- Session-Based Performance Optimization: The full intro sequence is cached via sessionStorage to ensure it plays only once per browser session, providing instant workspace access on subsequent revisits.

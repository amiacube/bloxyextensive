# Bloxd.io Code & Command Generator

A standalone web application for generating **WorldBuilder commands** and **Code Block JavaScript API** scripts for Bloxd.io private lobbies.

## 🎮 Features

### WorldBuilder Commands
- **//set** - Fill selected region with a block
- **//replace** - Replace specific blocks with another
- **//stack** - Repeat current selection directionally
- **//rotate** - Rotate copied clipboard structures
- **//schematic** - Save or load structures

### Code Block JS API
- **Player Launch Pad** - Boost velocity upwards
- **Transform into Zombies** - Convert players into zombies
- **Speed Buff** - Apply speed multiplier to player
- **Teleport Trigger** - Teleport to specific coordinates

## 🚀 Usage

1. Open `index.html` in your web browser
2. Select your desired mode (WorldBuilder Commands or Code Block API)
3. Choose an action/template
4. Fill in the parameters
5. Copy the generated code to your clipboard
6. Paste into your Bloxd.io lobby

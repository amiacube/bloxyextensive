📚 Bloxd Modrinth Information Guide

Mods Tab

Mods are standard, general modifications for your Bloxd world. When uploading a Mod, you can provide World Code (scripts pasted into the main World settings) and a Code Block (scripts pasted into command blocks inside the world). Use this for simple snippets and lobby setups.

Texture Packs Tab

Visual assets that replace standard Bloxd blocks, GUIs, and items. You can provide a direct URL to a hosted texture pack, or manually upload a .zip file for others to download.

Plugins Tab and Guide

What is the Plugins Tab?
The Plugins Tab is a specialized section of Bloxd Modrinth for sharing advanced, high-performance server modifications. Unlike regular mods that might just run once or use simple event listeners, Plugins here use a structured framework to safely execute code repeatedly without breaking the game.

Why are Plugins so important?
Because Bloxd.io runs inside a secure web sandbox, if you put heavy scripts or endless loops (like while(true) or zero-delay timers) directly into a Code Block, you will cause massive lag, frame drops, or even crash the server! Plugins solve this by splitting your code into two parts: a Loader that carefully manages timing, and a Payload that holds your actual game logic.

How does it work?
Plugins use a system called TPS (Ticks Per Second). The Bloxd API has a native tick event that runs exactly 20 times every second. The World Code (Loader) hooks into this heartbeat and broadcasts it safely. The Code Block (Payload) listens for this heartbeat and only runs its code when told to. This keeps everything perfectly synced, lag-free, and safe for large servers.

How to Install (Put) a Plugin:

  1. Copy the World Code Loader and paste it into your world's main "World Code" settings.
  2. Copy the Code Block Payload, place a command block in your game, and paste it inside.
  3. Play! The Code Block will automatically connect to the World Code API.

How to Create Your Own Plugin:
Instead of just copying our code, you can build your own using the Plugin System! Here is how the system works using the Bloxd API:

  • First, your World Code sets up a global object using globalThis.PluginAPI (since the window object is blocked in Bloxd).
  • The World Code then hooks into Bloxd's native tick = (ms) => {} function to create the heartbeat.
  • Then, your Code Block registers a function using globalThis.PluginAPI.register(callback).
  • The callback receives a tickCount number. For example, to run something every 1 second, you check if (tickCount % 20 === 0) { ... }. To run something every 5 seconds, use if (tickCount % 100 === 0) { ... }.
By understanding this architecture, you can insert any custom game logic, create multiple Code Blocks that all listen to the same Loader, and build massive server economies, minigames, or moderation tools entirely on your own!

System Example 1: The Loader (Goes in World Code)

/* === BLOXD PLUGIN LOADER === */
/* Initialize the global Plugin API */
globalThis.PluginAPI = globalThis.PluginAPI || {
    ticks: 0,
    listeners: [],
    register: function(fn) { this.listeners.push(fn); }
};

/* Use Bloxd's native tick event (runs 20 times per second) */
tick = (ms) => {
    globalThis.PluginAPI.ticks++;
    globalThis.PluginAPI.listeners.forEach(fn => fn(globalThis.PluginAPI.ticks, ms));
};

System Example 2: The Core (Goes in Code Block)

/* === BLOXD PLUGIN CORE === */
if(globalThis.PluginAPI) {
    globalThis.PluginAPI.register((tickCount, ms) => {
        /* Run custom logic every 1 second (20 ticks) */
        if(tickCount % 20 === 0) { 
            /* Use broadcastMessage because tick events don't have a playerId(maybe) */
            api.broadcastMessage("Plugin is running lag-free!", { color: "lime" });
        }
    });
}

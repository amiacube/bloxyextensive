Bloxd SDK Compiler

Setup and develop modular Bloxd.io code scripts offline using modern compilation compilers.

Cross-Platform Quickstart

1. Install Node.js
Ensure Node.js is installed. Node.js is completely cross-platform and supports all distributions of Windows, macOS, Linux, and ChromeOS natively.

2. Establish Workspace
Create a local directory on your machine (e.g., ~/BloxdModProject) and open this folder using VSCodium or your preferred text editor.

3. Download SDK Core Files
Acquire bloxd-helper.js from the downloader panel below and save it inside your project root directory.

4. Start modular coding
Using your terminal, initialize and compile your project structure with single commands. No complex external environments required!

Terminal Command Hub

node bloxd-helper.js init

Configures folder layouts under /src and creates sample template files (ticks, chats, README.md) with boilerplate codes.

node bloxd-helper.js build

Parses, resolves imports/entrypoints, merges, and minifies your source files into a unified, copy-pasteable dist/bloxd-code.js.

node bloxd-helper.js stats

Analyzes compiled script size, counts characters count limits, and flags redundant event hook performance bottlenecks.

node bloxd-helper.js help <command>

Full detailed guide and information for compiling commands. Example: bloxd help build or bloxd help init to learn exactly how it works.

Operating System Specific Setup

Windows Environment

Create and use bloxd.bat next to bloxd-helper.js in your folder. Once placed, you can run simple shorthand actions in CDM/PowerShell:

bloxd init
bloxd build
bloxd stats

macOS, Linux & Chromebook

Open your Terminal (zsh / bash) in the workspace. Run commands using standard Node execution or set up a shell alias for native look:

alias bloxd="node bloxd-helper.js"
bloxd init
bloxd build

How to Load into Bloxd.io:
  1. Download a standard desktop browser userscript manager extension (e.g. Tampermonkey).
